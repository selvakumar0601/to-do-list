# Simple To-Do List

A simple and responsive To-Do List application built using HTML5, CSS3, and JavaScript.

This project allows users to add and delete tasks. Tasks are stored temporarily in a JavaScript array, so they disappear when the page is refreshed.

## 🚀 Features

- Add new tasks
- Delete tasks
- Press Enter to add a task
- Empty task validation
- Dynamic task rendering
- Event delegation for delete buttons
- Responsive design
- Clean and simple user interface
- In-memory task storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
